# Archive UX — V1

The Archive is the primary browsing surface of Serendipity.

## Hierarchy

1. Archival index label
2. Large editorial title
3. One-line explanation
4. Category index
5. Contextual tools: Search / Discover
6. Irregular editorial image grid
7. Metadata on every item

## Item behavior

Every archive item exposes:

- archive number
- entity type
- title
- original-language title where relevant
- short description
- place
- date
- save action
- direct entity link

## Filters

Primary:

- All
- Objects
- Places
- Craft
- Art
- People
- Ideas

Secondary, when the dataset supports them:

- tag
- city
- country
- material
- period

Filters must never turn into a dense dashboard. They remain editorial index controls.

## Empty state

Use editorial language:

> NO FINDINGS.
> TRY ANOTHER TRACE.

## Responsive behavior

Desktop: controlled 12-column composition with deliberately offset imagery.

Tablet: reduce the number of columns while retaining uneven rhythm.

Mobile: preserve the archive feel through vertical sequencing and strong typography instead of simply shrinking the desktop grid.
